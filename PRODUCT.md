# K3 portrait touchscreen

A React/TypeScript kiosk interface for Klipper and Moonraker on a Waveshare 7.9-inch, 400×1280 portrait screen. Based on tdunl410/printer-ui-klipper; this repository retains its K3 printer render, existing routes, HTTP/WebSocket transport, and installation scripts.

The user's two original screenshots are the visual authority: charcoal surfaces, purple selected actions, generous touch targets, a large printer render with temperature chips, a prominent Print button, a circular XY jog pad, and the four labeled Home / Print / Control / Settings tabs. Preserve that composition. Do not substitute HelixScreen's native dashboard or an icon-only grid.

Mode: Operate. Priorities: clear printer state, predictable touch controls, reachable emergency stop, legible telemetry, and easy local appearance customization. Never represent disconnected readings as live printer telemetry. Browser verification uses isolated intercepted requests; physical hardware and a live printer remain unverified.
